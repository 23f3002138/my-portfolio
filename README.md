# Yaswanth Vaddi — Personal Portfolio

A premium, high-performance personal portfolio website built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

The portfolio showcases **Yaswanth Vaddi**'s multidisciplinary background across **Mechanical Engineering, Data Science (IIT Madras BS), Software Development, Machine Learning, Data Analytics, and Interactive/XR Technology**.

---

## Featured Projects

1. **Software Engineering Team Platform** (`agarwal-muskan/MAY2026-Team-006`)
   - Software Engineering Team Project. Modular full-stack web application & team software architecture.

2. **Hospital Management System V2** (`23f3002138/Hospital_Management_App_V2_23f3002138`)
   - Vue 3 SPA + Flask REST API with Celery background task processing and Redis message broker. Features automated daily appointment reminders (Celery Beat) and asynchronous PDF/CSV exports.

3. **Quiz Master Platform** (`23f3002138/quiz_master_23f3002138`)
   - Interactive assessment engine built with Flask, Flask-SQLAlchemy, Flask-Login, featuring admin subject/chapter hierarchy, real-time timed quiz evaluation, and user performance history.

4. **Business Data Analytics & Decision Optimization** (`23f3002138/BDM-Capstone-Data-Analysis`)
   - Data Analytics Capstone applying RFM behavioral customer segmentation, ABC inventory classification, SARIMA time-series forecasting, and pricing/margin scenario modeling.

5. **Cinema Audience Forecasting** (`23f3002138/cinema-audience-forecasting`)
   - Kaggle Machine Learning Competition project predicting theater audience attendance using LightGBM and CatBoost GBDT regressors with rolling 7-day statistics and temporal lag feature engineering. Achieved Kaggle score of **0.27**.

6. **RehaX — Interactive XR Rehabilitation Technology**
   - Internship Project (Private Repository). Interactive XR rehabilitation platform combining real-time motion tracking, bio-mechanical feedback visualization, and therapeutic exercise environments.

## Tech Stack & Architecture

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion (GPU-accelerated, 60 FPS)
- **Icons**: Lucide React
- **Design Aesthetic**: Modern 2026 dark engineering theme with interactive node canvas hero and glassmorphism.

## Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
